# Standards

## Python

- **Types:** annotate every function signature, parameters and return type, using modern syntax
  (`X | None`, builtin generics). `uv run mypy src` must stay clean.
- **Docstrings:** every module, class and function (nested ones too) gets a one-line
  imperative docstring. `uv run interrogate src migrations` enforces 100%.
- **Lint:** `uv run ruff check src tests migrations`.
- **Settings:** each settings group has its own `env_prefix` (`LLM__`, `RAG__`, `OTEL__`, ...).
  Never read bare environment names. Unknown settings are rejected, so after adding one, rebuild the
  images before `docker compose up -d` (the `migrate` container bakes in the code).
- **Migrations:** Alembic, reviewed by hand. The autogenerated output re-detects known TEXT/AutoString
  drift, so keep only your change, check `downgrade`, and run `upgrade head`.

## Agents

- An agent change covers a role spec, a prompt, a tool or a workflow. Every such change runs the
  affected eval suites on LM Studio:

  ```bash
  uv run python -m draftpilot.evals <suite>
  ```

- A deliberate quality change updates `evals/baselines/` in the same commit.
- **Test determinism:** tests use `FunctionModel` or `TestModel`. `ALLOW_MODEL_REQUESTS=False` is
  enforced, so a test can never reach a real model. Tier 1 (`-m lmstudio`) is the only place a real
  model runs.
- **Writes:** agents propose; they never apply. New write paths must go through proposals or MCP
  approvals.

## Frontend

- React 19 with TypeScript. Every colour is a theme token from `src/theme.css`, and new CSS must use
  tokens, never hex values.
- Controls need accessible names, because Playwright selects by role and label.
- `npm run build` (typecheck plus build) and `npm run test:run` (Vitest) must pass.

## Tests

See [Testing](../testing.md) for the tiers. New behaviour gets a deterministic test (Tier 0 or e2e).
Behaviour that depends on a real model also gets a Tier 1 test or an eval case.

## Git

- Work on issue branches (`amruthvvkp/issueN`) and reference the issue in each commit.
- Commits are signed.
