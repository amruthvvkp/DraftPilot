# Projects

Each story lives in its own project. **Projects**, the first page of the studio, is your library:
open a project, start a new one, copy or delete one, and bring back one you deleted.

## The library

Every project is a card with its artwork (or its first letter), title, logline and up to three
genres. Click a card to open the project. A card's **⋯** menu holds **Duplicate** and **Delete…**.

The last card, **Begin a new project**, and the **New project** button at the top both open the
new-project wizard. **Recently deleted** appears below the library when there is something to
restore.

## Start a new project

The wizard has four steps. Only the title is required; everything else can wait, and all of it stays
editable later.

1. **Brief**: the project title, a logline and genres.
2. **World**: a description, story outline notes, camera (Digital, Film, Animation, Mixed),
   screening format (Flat 1.85, CinemaScope 2.39, and others), the primary screenplay language, and
   any dialogue translation languages.
3. **References**: typed creative references (films, directors, styles, reference scenes, camera,
   lighting, colour palettes, locations), each with an optional link and note, plus artwork as a
   link or an image from your computer.
4. **Review**: check it, then **Create project ✦**.

DraftPilot opens the new project on its **Script** page, with an empty first draft ready for its
first scene.

!!! note "Languages"
    Scene headings and action are written in the primary language. Translation languages are only
    for dialogue, so the primary language can't also be a translation language.

### Spark with AI

On the **Brief** step, **Spark with AI** turns an idea into a first brief. Type a premise ("A haunted
lighthouse keeper discovers radio signals from the future…") and press **Spark story ✦** or
++enter++. It fills in the title, logline, description, story outline, genres, camera, screening
format and visual style. Fields it leaves empty keep what you typed. Change anything before you
continue.

Spark uses your default model. If no model is available, it still fills the form from your premise,
with simpler results.

## Start from an existing screenplay

To bring in a script you already have, create a project for it (a title is enough), then on the
**Script** page press **Import** and choose the file:

| Format | File |
|---|---|
| Fountain | `.fountain` or plain text |
| Final Draft | `.fdx` |
| PDF | `.pdf` |

Files up to 10 MB are accepted. The import becomes a new draft named "… (Imported)", and the editor
switches to it; the **Draft** picker switches back. An import never replaces existing work, and
the new draft is queued for indexing so the room can search it.

If the file can't be read, the header shows **Import failed** with the error code; check that the
file really is in the format its extension says.

## Open a project

Click its card. The project opens on the **Script**, with the
**Storyline → Characters → Outline → Script** stepper at the top. What to do from here is in
[Develop a story](guided-flow.md).

## Duplicate, delete and restore

- **Duplicate** (in the card's **⋯** menu) makes a full copy named "*title* (copy)".
- **Delete…** asks you to type the title, then removes the project. A backup is kept first.
- **Recently deleted → Restore** brings a deleted project back from that backup.

What a copy or a restored project contains, and what deleting loses for good, is in
[Backups & recovery](backups.md).
